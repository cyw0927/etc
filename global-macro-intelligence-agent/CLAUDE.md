# CLAUDE.md — GMIA 온보딩과 협업 지침

이 문서는 Claude/Claude Code 및 다른 AI가 이 프로젝트를 **한 번에 읽고 동일한 원칙으로 분석**하기 위한 진입점이다.

## 지금 할 일
현재는 구현 단계가 아니라 **가상 세계경제 시나리오 기반 개념검증**이다. 사용자가 구현을 별도로 요청하기 전에는 코드를 만들거나, 외부 API를 설정하거나, 저장소 기존 파일을 수정하거나, 실제 매매를 실행하지 않는다.

## 필수 읽기
1. `README.md` — 목적, 순서, 대상
2. `prompts/01_master_gmia_v0_1.md` — **전체 요구사항이 담긴 기준 문서**. 절대 요약만 읽고 수행하지 말 것
3. `prompts/02_independent_review.md` — 다른 모델의 결과를 비판하는 프로토콜
4. `prompts/03_synthesis_improvement.md` — 이견 조정과 개선 프로토콜

## 역할별 작업
- **최초 분석 담당**: 01 전체 읽기 → 실험 001 분석 → 1주·1개월·3개월 전망과 시나리오 → 다음 AI 인계 요약
- **독립 검증 담당**: 02 전체 읽기 → 원본 결과의 경제 논리·출처·가정·반례·확률 주장 검증 → 수정 요청
- **통합 담당**: 03 전체 읽기 → 둘의 이견을 근거로 판정 → 버전별 개선안 + 다음 실험 제안

## 절대적 분석 원칙
1. 실험 001은 **전부 가정된 가상 사건·수치**다. 2026년 실제 경제 데이터라고 주장하지 말 것.
2. **SIMULATION MODE**와 **REAL DATA MODE**를 혼합해서 그럴듯한 실측 예측처럼 제시하지 말 것.
3. 실측값이 필요하면 공식 자료와 다양한 해외 보도를 검색하고, 기준일·발표일·사건일을 각각 기록할 것.
4. 한국 언론의 국제뉴스 2차 보도는 기본 수집원에서 제외하되, 한국은행·통계청 등 한국 공식 경제 원자료는 허용한다.
5. 전쟁·국제정세는 사실 / 당사국 주장 / 제3자 검증 / 추론을 반드시 구분한다.
6. 동일 출처를 인용한 복수 기사를 독립된 확인으로 간주하지 않는다.
7. '긍정·부정·모호함'은 대상 자산이나 국가·산업의 관점에서 분류한다.
8. 자산가격 수준, 수익률, 국채금리(%), 금리 변동(%p), 환율의 표기 방향을 혼동하지 않는다.
9. PER/PBR 숫자만으로 저평가·고평가를 단정하지 않는다.
10. LLM이 떠올린 수치·확률은 **검증된 모델 예측이 아니다**. 미검증 예상에는 반드시 '가상/설명용' 라벨.
11. 시장의 사전 기대, 가격 선반영, 경기국면, 제3 변수, 반대 시나리오를 분석한다.
12. 과거 시점 테스트에서는 그 시점에 사용 가능했던 정보만 쓴다(미래정보 유출 금지).
13. AI 두 개가 합의했다는 사실만으로 정확성을 주장하지 않는다. 검증 가능성·독립 자료 우선.

## 보고서 최소 출력 형식
- 분석시점 / 모드 / 데이터 출처 / 확인 상태
- 경제권별 현황 및 상호 파급경로
- 금융시장과 기업 가치평가
- 주요 지정학적 사건: 사실확인 수준과 자산별 영향
- 기본·낙관·비관 시나리오
- 자산별 1주·1개월·3개월 판단(불확실성, 반대 조건 포함)
- 핵심 누락 데이터 및 모델의 취약점
- 다음 AI를 위한 검증·인계 요약

## 파일 관리
원본 프롬프트 3개는 최초 기준안이다. 향후 수정 시 이력과 버전 번호를 남기고, 기존 요구사항의 의미를 임의로 삭제하지 않는다. 사용자가 요청하지 않은 실거래나 자동 발주는 구현하지 않는다.

**첫 요청 예시:** "이 저장소의 `global-macro-intelligence-agent/CLAUDE.md` 및 README와 `prompts/`의 3개 문서를 순서대로 전부 읽고, 01 마스터에 담긴 가상 시나리오 001을 실행해 줘. 코드 작성은 하지 마."
