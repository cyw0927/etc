# 시장·기업 재무·가치평가 계약

상태: 기존 시장 일봉과 금리 피처만 실행 가능. 아래 instrument master와 기업 재무 계층은 **설계**다.

## 시장 계측

각 instrument는 base/quote currency, 시장 timezone, session open/close/break, 실제 거래소 calendar와 버전, 가격종류(raw/배당조정/분할조정/total return), settlement vs last trade, vendor cutoff, contract/roll 규칙, 유동성·거래량 가용성 계약을 가진다. FX 장외 종가·선물 정산·지수 종가를 주식 거래소 종가와 동일시하지 않는다. 조기 폐장·공휴일·DST·누락봉을 구분한다.

수익률은 현지통화와 기준통화 변환을 별도 저장한다. 원화 투자자의 USD자산은 일치 cutoff의 FX 수익과 결합하며 이미 원화 가격인 자산에 환율을 중복 반영하지 않는다. FX 표기 역수이면 수익률 방향도 바뀐다. 채권은 수익률 곡선의 금리 수준/변화와 실제 채권 가격·듀레이션·쿠폰 총수익을 별도 타입으로 둔다. GLD는 보수·추적오차가 있고 금 현물과 같지 않다.

WTI 연속선물은 만기별 계약·롤 날짜·조정법과 실현 가능한 비용을 따로 기록해야 한다. 음수 가격은 로그 수익률에서 사용할 수 없지만 경제적으로 불가능한 관측은 아니다. 기존 코드의 결측 처리는 계산 제약이며 사건 삭제/수익성 근거로 사용하지 않는다. BTC 거래일은24/7 UTC, 소스별 거래소 집계/봉 경계가 다를 수 있어 빈 날짜 검사를 필수화한다.

추가 후보 데이터는 변동성지수·신용스프레드·실질/명목 수익률곡선·유동성·시장깊이/거래대금이다. 현재 입력에 있다고 주장하지 않는다. 공식/허가 공급원을 선정하고 과거 시점의 이용가능성을 고정한 뒤 별도 피처 연구에 등록한다.

## 재무 fact와 회계 정합성

미국은 SEC submissions+접수 accession+XBRL, 한국은 DART 공시접수번호+재무제표/XBRL 원문을 우선한다. companyfacts의 현재 응답만 받아 결산일에 이미 알려졌다고 가정하지 않는다. `entity_id, security_id, accession, accepted_at, fiscal_start/end, period_type, form, concept, unit, dimensions, consolidated, accounting_standard, value, amendment_of, snapshot_id`를 보존한다.

연결/별도·지배주주/전체·보통주/희석주식수·통화·주식분할을 맞춘다. US GAAP/IFRS 차이·금융업/비금융업 지표 차이를 설명한다. 누적 분기 현금흐름의 차감은 동일 빈티지/범위일 때만 하며 연간+중간기간 이중합산을 막는다. 정정은 새 버전이고 원보고 시점 재현을 유지한다. 상장폐지·종목 변경과 당시 지수 구성/가중치 이력 없이 현재 구성종목을 과거로 소급하지 않는다.

| 지표 | 정의/시점 계약 | 결측/오해 방지 |
|---|---|---|
| trailing PER | 가격과 당시에 공시된 TTM 보통주 EPS, 희석/분할 기준 명시 | EPS≤0은 N/M; 현재 수정 EPS 과거 대입 금지 |
| forward PER/EPS revision | 같은 컨센서스 공급자·전망기간·as_of | EDGAR/DART에서 미래 컨센서스를 얻는다고 가정 금지; 계약 없으면 미제공 |
| PBR | 시가총액/같은 범위의 최신 공개 보통주 자본 | 음수 자본·자사주·기준통화 설명 |
| ROE | 귀속이익/일관된 평균 귀속자본 | 일회성 이익·레버리지·회계기간 영향 |
| ROIC | 조정 NOPAT/평균 투하자본, 세율·영업/금융 항목 규약 | 금융업 동일식 적용 금지; 추정 조정은 별도 |
| FCF | 영업현금흐름−명시한 자본적지출 | 유지/성장 CAPEX 구분 가능성·누적기간 차감 |
| EV/EBITDA | 시가총액+부채+우선/비지배−현금, 동일시점 TTM EBITDA | 리스/금융부채·비경상 조정 명시 |
| 부채·배당 | 만기·금리·배당 발표/권리락/지급시각 구별 | 배당을 수정종가 총수익에 이중계산 금지 |

가치평가 화면은 지표 숫자와 함께 공시 링크·기간·계산식·분모·신뢰도·갱신시각을 보여준다. 업종 구성/금리/성장/자본비용과 함께 해석하며 PER/PBR 하나로 저평가를 단정하지 않는다. 누락 재무값·컨센서스·지수 구성은 가짜 값으로 메우지 않는다.

수용조건: 최초/정정공시 replay, 같은 기간·단위·연결범위 fact 선택, filing acceptance 이전 차단, 누적/분기 혼동·EPS≤0·음수자본·주식분할 사례, delisted 포함 universe 검토. 초기 한미 각2개사 실제 공시로 수작업 대조하고 검증된 필드만 확장한다.
