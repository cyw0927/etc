# 조건부 시나리오와 스트레스 엔진

상태: **미구현 설계**. 정량 추정과 LLM 정성 시나리오는 별도 타입으로 저장하고 표시한다. 시나리오가 통계 예측확률을 바꾸지 않는다.

`scenario_id, created_at, as_of, shock_variables, path_by_horizon, transmission_edges, assumptions, estimated_parameters_version, uncertainty_method, counter_path, invalidation_rules, evidence_ids, scenario_type`를 계약으로 한다. 타입은 `estimated_conditional` 또는 `qualitative_hypothetical`이다. 임의의 상방/기본/하방에 합계 100%를 붙이지 않는다.

| 충격 구분 | 중간 변수와 2차 경로 | 자산별 양방향·반증 |
|---|---|---|
| 미국 실질금리 상승 | 할인율↑·달러·금융여건 | 성장주/금 부담 가능. 성장 개선이 원인이면 이익 증가가 상쇄; 명목금리만으로 실질금리 추정 금지 |
| 기대인플레 주도 금리 상승 | 마진·실질임금·통화정책 반응 | 에너지/가치주와 장기채의 효과 상이. 기대인플레와 기간프리미엄 분해 불확실 |
| BOJ 정상화·엔 캐리 청산 | 금리차→엔화→펀딩/레버리지→국제 자금 | 수출기업 환산이익/수입비용 혼합. 엔 강세가 항상 위험자산 하락을 뜻하지 않음 |
| 중국 내수 부양 | 소비·수입·한국 소비재/수출 | 재정 전달·가계 신뢰가 약하면 효과 제한 |
| 중국 인프라 부양 | 금속·에너지·산업재 수요·재고 | 소비 부양과 구성 다름; 기존 과잉투자가 누수 |
| 중동 실제 공급 차질 | 생산/수송 물량↓→재고·운임·원가 | 공급 유지 산유국과 수입국 비대칭, 비축 방출/우회로가 상쇄 |
| 공급 우려만 확대 | 옵션/보험료·위험프리미엄 | 실제 수급 손실 없음 확인 시 되돌림; 물량충격과 같은 크기 금지 |
| 공급 충격 vs 디레버리징 | 원가 인플레 vs 달러/현금 수요·담보 청산 | 금·BTC도 유동성 강제매도로 하락 가능; 안전자산이라는 말로 방향 고정 금지 |

처음엔 과거 release-aware 데이터의 단순 조건부 분포/민감도 표를 사용한다. 구조모형 식별이 안 되면 '1% 충격의 인과효과'로 표현하지 않는다. 경로별 입력·파라미터·추정구간을 동결하고 Monte Carlo seed·상관구조/중복 경로를 기록한다. 정성 경로의 수치가 필요하면 사용자 가정으로 표시하며 검증된 forecast와 합성하지 않는다.

수용조건: 충격 단위(% vs %p) 검증, 공급/수요 충격 구분, 국가·산업·자산별 반대 조건, 변수 중복 효과 방지, 미확인 경로 보류, 보존된 시나리오 재실행 동일성, 과거 결과를 보고 가정을 맞춰 쓰지 않았는지 시각 감사. 성공은 근거와 조건의 투명성이지 전망 적중 보장이 아니다.
