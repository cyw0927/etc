# GMIA 비전과 현재 경계

기준일: 2026-10-28 (한국). 감사 기준 코드 `b63f831261a11427f750937b3cb7c2b021abfd38`.

GMIA는 세계경제·금융시장·기업가치·국제정세를 근거와 시점에 연결하고, 발행한 예측을 시간이 지난 뒤 평가하는 개인 연구 플랫폼이다. 더 복잡한 모델을 추가하는 것보다 당시 알 수 있었던 데이터와 재현 가능한 비교를 우선한다. 현재 시스템을 수익성 있는 투자 시스템으로 간주하지 않는다.

## 현재 가능한 것

- **구현**: Yahoo 10개 시장 시리즈, FRED 금리 3개와 표시용 거시 4개. 수익률 기반 특징, 15 후보(입력 없으면 일부 제외), 9자산×5/20봉, 워크포워드·보정·HAC/BH, 로컬 SQLite 예측·첫 채점, Streamlit 6개 화면.
- **부분 구현**: ALFRED 빈티지 어댑터와 합성 테스트. 실제 키 실행·발표시각 검증은 미완료. 날짜 strict join은 타임스탬프 PIT가 아니다.
- **이번 구현**: 불변 수집 스냅샷·무결성 검증·실행별 입력 포인터, 정확한 발표/수집시각의 적격성 계약, SQL 수정/삭제 방지, 수동 온라인 백업과 복원 검사.
- **미구현**: 다국가 거시·기업 재무·합법적 외신 수집과 사건 검증·조건부 스트레스 엔진·운영 API·운영 스케줄·클라우드 배포. 현재 표시값으로 채워 넣지 않는다.

v0.3의 '252개 중 지지 0개'는 기존 실행 보고이며 이번 변경으로 개선됐다고 주장하지 않는다. 과거 홀드아웃은 이미 노출됐다. 실데이터를 새로 받으면 과거 수정종가와 지표가 바뀔 수 있으므로 결과의 숫자 동일성보다 입력 스냅샷 동일성을 먼저 검증한다.

## 제품이 답해야 할 질문

1. 어느 국가의 성장·물가·정책·유동성이 어떤 근거로 바뀌고 있는가?
2. 자산 사이 관계가 어느 기간과 시장 시각에서 관측되며 반대 설명은 무엇인가?
3. 기업의 가격과 그때 공시된 이익·자본·현금흐름이 어떤 가정 아래 연결되는가?
4. 실제 사건인가, 당사국 주장인가, 독립 확인인가? 동일 원출처를 몇 번 반복했는가?
5. 통계 예측이 기준모델보다 나았는가? 표본이 부족하면 무엇을 아직 말할 수 없는가?

## 범위 원칙

모듈러 모놀리스와 독립 워커를 우선한다. LLM은 근거를 정리하되 모델 확률을 덮어쓰지 않는다. 연구 가설 추가는 별도 사전등록 커밋 후 전진 검증한다. 원본 프롬프트와 v0.3/v0.4 등록 문서는 보존한다. PR #1/#2 설명·코드·병합은 이번 작업에서 변경하지 않는다. main 직접 푸시·자동운영·외부 배포·과금은 하지 않는다.
