# 공보 이용 조건 및 거시 수정 관측

## WTI 공보

CME는 웹에서 정산자료를 무료로 볼 수 있지만 [시장자료 이용조건](https://www.cmegroup.com/trading/market-data-explanation-disclaimer.html)은 서면 허가 없이 웹 자료의 자동 수집·데이터베이스 구축과 AI/ML 이용 등을 제한한다. [거래소 공지](https://www.cmegroup.com/notices/clearing/2023/12/Chadv23-364.html)도 스크립트로 웹 자료를 수집·분석하는 행위를 제한한다. 실제 PDF 자동 요청도 시간 초과였다. 따라서 공보 자동 수집, 데이터 저장 및 롤 계열 구축은 수행하지 않았다. 이 조건은 무료 열람과 다르며 유료라고 단정하지 않는다. 허가된 공급원 또는 CME의 해당 용도에 관한 서면 허가가 확보되면 계약 ID·거래일·정산값·만기·전환 규칙·접수 시각을 확인하고 별도 사전등록 후 구현한다. 이전 예측의 WTI 차단은 유지한다.

## 거시 수정 관측

`compare_fred_observations.py`는 두 수집본의 원본 해시·시각·시리즈 ID를 확인해 최신 관측치와 FRED의 시리즈 갱신 표시가 바뀌었는지 비교한다. 각각의 실제 요청·수신 시각을 출력한다. 이 결과는 두 번의 관측 비교이며 이전 기간 수정, 그 사이에 여러 차례 바뀌었다 복구된 값, 원 발행자의 정확한 수정시각은 증명하지 않는다. FRED `Updated`의 분 단위 표시는 시리즈 전체의 최신 갱신을 의미하며 개별 관측값이 최초로 제공된 시각이라고 간주하지 않는다. 기존 ALFRED 빈티지는 날짜 수준이다.

```powershell
.\.venv\Scripts\python.exe scripts/collect_fred_pages.py
.\.venv\Scripts\python.exe scripts/compare_fred_observations.py --before <이전_수집본> --after <새_수집본>
```

기존 전진 예측 발행기는 FRED 수집 시작 후 15분이 지나면 해당 입력을 차단한다. 사전등록의 36시간 허용범위보다 엄격한 운영 제한이다. 발행 당일 수집해도 모든 중간 수정이 포착됐다는 보장은 없다. ALFRED에 대한 기존 이틀 지연 연구 가정과 고정된 공식 발표 기준시각 확인 범위를 유지한다. 기존 장부 및 과거 예측을 수정하지 않는다. 새 관측이 발생할 경우 현재 규칙과 공식 근거가 맞지 않으면 발행은 보류된다.
