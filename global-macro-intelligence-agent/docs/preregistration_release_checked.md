# 거시 발표·FRED 갱신시각 대조 전진 예측 사전등록

이전 모든 사전등록과 장부를 변경하지 않는다. 기존 연구 모델 `b08139784b0881dc2147584ed873bbb417326a231c78f2623addf28e0b1e568c` 및 SPY 5 NYSE 거래일 상승 라벨을 유지한다. 다만 이전 모델의 이틀 지연을 유지하면서 공식 발표 기준시각과 FRED 최신 자료를 추가로 대조하는 별도 가족 `macro_release_checked_v1` 및 별도 장부를 사용한다. 기준시각은 공식 발표문에 적힌 엠바고 종료 또는 공식 일정의 예정시각으로, 실제 업로드 순간이나 과거 FRED 빈티지별 공표시각과 동일하다고 가정하지 않는다.

이번 프로토콜에서 확인한 2026년 9월 관측치에 한해 다음 시각을 사용한다: CPI 10월 14일 08:30 ET(노동통계국 발표문 엠바고); 실업률 10월 2일 08:30 ET(고용 발표문 엠바고); 산업생산 10월 16일 09:15 ET(G.17 발표문); M2 10월 27일 13:00 ET(연준 공식 일정). 이 시각과 별도로 FRED 각 시리즈 웹페이지의 `Updated` 표시(분 단위), 페이지 본문의 관측월과 값, 현 시스템의 실제 요청·수신 시각 및 원본 해시를 남긴다. FRED `Updated`는 해당 개별 값의 최초 공개를 확정하지 않는다. BLS 원문 자동 요청이 차단되었으므로 근거는 공식 웹문서 확인이며 수집 서버에서의 원문 보관을 주장하지 않는다.

발행 전 4개 모두 다음을 만족해야 한다: 현 시점 값과 관측월이 FRED 최신 페이지와 ALFRED 선택값에 정확히 일치; ALFRED 수정일과 FRED 갱신일이 위 발표일과 일치; 각 발표 기준시각 및 FRED 갱신 분의 끝이 수집 요청 이전; 원본 응답 수신·ALFRED 수집·가격 수집·모델 학습이 실제 발행 이전; 모든 페이지 해시 검증; 현재 수집본의 연속성과 36시간 이내 최신성. 값·날짜 변경이나 새 수정이 생기면 확인되지 않은 사실을 대신 입력하지 않고 차단한다. 일치 검사는 입수 가능한 증거에 한하며 FRED 갱신표시가 개별 값이 정확히 언제 공개됐는지 증명하지 않는다.

기준 SPY는 NYSE 최종 완료 봉 +15분 이후 수집하고 다음 정규장 개장 전에 발행한다. model hash, source hash, 발표시각 유형, FRED 갱신시각, 실제 수신시각, ALFRED 수정기간, 거래일과 발행시각은 `data/operations/macro_release_forward/ledger.sqlite3`에 최초 기록한다. 기존 장부를 변경하지 않는다. 확률·데이터가 달라진 동일 키는 충돌로 차단한다. 만기는 5거래일 후로 기존 규칙과 같은 독립 채점, 최초 점수 고정, Brier 기술통계만 허용한다. 모델 우위나 유의성 판정은 수행하지 않는다. 유료 가입, 외부 배포, 자동 스케줄은 하지 않는다.
