# 거시 연구모델 전진 예측 사전등록

기존 15후보·홀드아웃·v0.4/v0.5 장부와 독립된 SPY 5거래일 상승확률 연구 장부를 새로 만든다. 이전 학습용 사전등록은 그대로 둔다. 이 문서는 구현과 이번 전진 예측 발행 전에 별도 커밋한다. 투자 성과나 예측력 우월성을 주장하지 않는다.

## 고정 후보와 자료

후보는 2026-10-28에 기존 사전등록에 따라 학습된 연구용 로지스틱 모델 하나이며 모델 JSON SHA-256은 `b08139784b0881dc2147584ed873bbb417326a231c78f2623addf28e0b1e568c`다. 4개 ALFRED 지표 CPIAUCSL, UNRATE, INDPRO, M2SL의 수준을 입력으로 사용하고 C=1.0 계수는 변경하지 않는다. 현재 수집한 거시 빈티지와 모델이 모두 발행 전에 도착·학습됐음을 확인한다. 4개 원본의 완전한 빈티지 목록과 원본 해시·수집시각을 검증하고 수집 시작 후 36시간이 지난 입력은 사용하지 않는다.

ALFRED가 제공하는 수정일의 정확한 일중 발표·실제 최초 관측 시각은 알 수 없다. 예측 시각의 UTC 날짜보다 이틀 이상 앞선 ALFRED 수정일의 자료만 사용한다. 이것은 별도 명시한 보수적 **날짜 기준 연구 가정**이며 발표시각 증명이 아니다. 해당 값이 발행 당시 로컬에 실제 수집 완료돼 있어야 한다. 과거 학습 값은 당시 수집했다는 주장을 하지 않으며 가격 수정종가도 과거 PIT 가격으로 간주하지 않는다.

## 최초 발행과 만기

SPY 기준일은 NYSE 최신 완료 거래일, 정규장 마감+15분 이후 받은 최신 Yahoo 스냅샷의 기준일이어야 한다. 발행은 다음 정규장 개장 이전에만 가능하며, 캘린더·거래일·결측·원본 스냅샷 해시·수집·학습 및 발행 시각·코드 상태를 검사하고 불일치하면 중단한다. 다섯 거래소 세션 후 수정종가가 발행 당시 기준 수정종가보다 높으면 1, 그렇지 않으면 0이다. 만기 전 자료를 사용하지 않고 기준~만기 사이 거래일이 모두 있는 스냅샷의 기준가격이 재조정됐으면 보류한다. 날짜별 발표 2일 가정과 Yahoo 15분은 공급자 확정 보증이 아니다.

발행은 `data/operations/macro_forward/ledger.sqlite3`에만 원자적으로 추가한다. 예측키 `(asset,forecast_date,horizon,model)`별 최초 확률과 기준가격, 실제 발행 UTC, 코드·모델·입력 해시와 지표별 사용 빈티지 및 수집시각을 남긴다. 동일 키는 최초 기록을 유지하고 다른 입력·확률은 충돌로 중단한다. 최초 점수는 같은 새 장부의 별도 append-only 표에만 기록한다. 기존 모든 장부를 수정하지 않는다.

라벨별 Brier 오차 `(p-y)^2`를 기록하며 표본외 설명적 자료로만 이용한다. 기존 홀드아웃·252개 검정과 합산하지 않고 통계적 유의성·모델 우위 판정은 수행하지 않는다. 향후 확증 검정은 표본·다중비교·중단 조건을 정한 별도 사전등록이 필요하다. 스케줄·배포는 자동 설정하지 않는다.
