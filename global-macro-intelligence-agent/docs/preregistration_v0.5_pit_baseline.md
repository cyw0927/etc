# GMIA v0.5 연구용 기준확률 발행: 사전등록

등록 상태: 구현·이번 프로토콜 실데이터 평가/예측 발행 전에 별도 커밋. 기존 v0.3/v0.4/v0.4.1 문서를 변경하지 않는다.

## 이미 알려진 것
기존 v0.3의 252개 검정은 지지 0개. v0.4 장부에는 270개 예측과 0개 점수가 있었으며 당시 BTC 봉 누락, FX/WTI 공급자 봉 정의 미확인, 일별 금리 발표 시각·수정값 누출 위험이 알려졌다. 기존 2024~26 홀드아웃은 반복 노출됐다.

## 목적·범위
시점 무결성이 검증된 수집본에서 새 예측을 실제 발행하는 최소 운영 경로다. 수익성·예측력 개선을 주장하지 않으며 기존 15개 후보군의 완성판으로 표시하지 않는다. 외부시장·금리·거시·뉴스·거래량 피처는 사용하지 않는다. 미국 ETF SPY/QQQ/GLD, KOSPI, NIKKEI에 한해 이미 존재하는 B1 과거 상승비율 개념을 독립 프로토콜로 사용한다. BTC·USDKRW·USDJPY·WTI는 공급자 봉 시간과 계약/롤 근거가 충족되기 전까지 발행하지 않는다. 기존 Yahoo 종목에 새 공급원의 종목을 대체하지 않는다.

## 발행 규칙
- 출력은 5·20 해당 거래소 봉 뒤 수정종가 상승 여부의 확률. 각 종목별 거래소 달력·DST·실제 정규장 마감+15분 이상 경과, 그 이후 실제 수집 완료 및 수집본 해시 확인, 현재 UTC 시각과 수집시각의 순서를 검증한다.
- 기준일은 최신 완료 거래일이어야 하고 발행은 그 다음 예정 거래일의 개장 전에만 허용한다. 실시간 완성봉/수집 시각이나 달력 확인이 불가하면 발행하지 않는다.
- 거래소 캘린더에서 확인한 과거 거래일 구간의 h봉 창에서 기준·만기 포함 모든 예상 거래일이 있고 수정종가가 유한한 양수인 것만 학습한다. 최신 기준일까지 완성된 라벨만 사용한다. 최소 학습 표본 252개. 확률은 y의 평균을 [1e-6,1-1e-6]로 자른다. 과거 원자료 수정은 당일 학습 입력으로 사용되나 역사 당시 그 버전이 알려져 있었다는 주장은 하지 않는다.
- baseline만 별도 로컬 `data/operations/issuance/ledger.sqlite3`에 최초 삽입한다. 이름/가족은 `pit_baseline_v0.5`, (기준일,자산,h,모델) 고유, 예측/메타/입력manifest를 같은 SQLite transaction으로 기록한다. 기존 v0.4 장부를 읽거나 수정하여 섞지 않는다.
- 신규 모델의 성능 확증, 모델 간 252개 검정, 사용자의 과거 장부 score 수정은 하지 않는다. 향후 후보/평가 계획은 이전 관찰·프로토콜을 명시한 별도 사전등록 후 수행한다.

## 필수 차단과 재현
source 관측·공표·수집 시간의 시간대가 없거나 공표/수집이 cutoff 이후, 레코드의 빈티지 적용범위가 cutoff를 덮지 못하거나 추정일뿐 증거가 없으면 입력을 차단한다. 월간 거시의 관측월은 발표일이 아니다. FRED DGS/DFF의 최신 수정 CSV는 개별 시각·수정 이력을 증명하지 못하므로 모델에 넣지 않는다. ALFRED 날짜만으로 일중 정확 발표시각을 주장하지 않는다. 가격 스냅샷도 historical PIT 전체의 증거가 아니며 vendor 재조정 가능성을 별도 표시한다.

발행 전 해당 자산 데이터 최근 거래일·누락·중복·가격·선행 라벨 끝 시각, Git/환경/달력 버전, snapshot pointer/hash, fetch 시작 및 ingest 완료 시각을 기록한다. 트랜잭션 실패 시 전부 rollback. 재실행시 첫 예측을 덮어쓰지 않으며 다른 확률·input이 이미 있으면 충돌로 중단한다. 기존 장부와 모든 원자료는 보존한다. 테스트는 인공 자료와 실데이터 preflight 및 별도 ledger 입력/무결성 확인으로 구분한다. 배포/스케줄 등록 없음.
