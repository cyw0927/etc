# GMIA 실제 ALFRED 빈티지 연결 시험 사전등록

목적은 키 없이 공식 ALFRED 웹 다운로드로 수집한 네 월간 지표의 날짜별 수정 이력을 기존 로지스틱 학습 코드에 연결하고 누출 방지 규칙이 실행되는지 확인하는 것이다. 수익률·성능·기존 모델 대비 우월성을 평가하지 않고 예측 확률을 발행하지 않는다. 기존 15후보, 5·20봉 정의, 원자료와 장부를 변경하지 않는다.

- 실험 대상 SPY, 5개 NYSE 세션 뒤 수정종가 상승 라벨. 2005년 1월 이후 현재 수집된 Yahoo 가격 스냅샷에서 거래소 달력의 기준일~만기일 전체가 있고 양 끝값이 양수이며 만기가 학습 기준일을 넘지 않는 경우만 라벨로 사용한다. 가격 시계열은 현재 스냅샷이며 과거 시점별 가격 빈티지나 최초 발표 당시 가격을 증명하지 않는다.
- 입력은 CPIAUCSL, UNRATE, INDPRO, M2SL의 수준값 네 개뿐. ALFRED가 제공한 수정일 단위 관측·실시간 기간을 그대로 사용하고 결정을 UTC 기준일보다 이틀 이전으로 제한한다. 이는 일중 발표시각이 없는 날짜 기반 연구 가정이며 당일 또는 익일 정보를 사용하지 않는 보수적 지연이다. 실제 과거 각 시점에서 수집했다는 뜻이 아니다.
- 학습용 모든 행은 결정시각을 NYSE 정규장 마감+15분으로 설정해 이틀 지연 후 이용 가능했던 빈티지를 선택한다. 종목 거래일 누락과 가격 결측, 날짜 또는 입력 해시 오류, ALFRED 원본 목록/파일 누락·충돌은 차단한다. 중복 수정 구간은 값과 기간이 완전히 일치할 때만 합친다.
- 최종 입력 자료는 실제 과거가 아닌 현재 수집된 재구성 이력이다. 현재 수집 완료 이전에 예측을 발행한 것으로 간주하지 않는다. 시간대가 없는 수정일을 개별 발표 시각으로 표시하지 않는다.
- 모델은 기존 `CompleteCaseLogit`, 네 특성, 기본 C=1.0, 완결된 라벨을 가진 행만, 튜닝 없음. 학습된 계수와 입력 provenance는 독립 `data/operations/source_research/` 아래 새 폴더에만 기록한다. **예측값을 기록하거나 발행하지 않는다.** 새 모델의 정량 평가·전진 예측 및 운영 경로 통합은 별도 사전등록과 미래자료 검증 후에만 한다.

ALFRED 다운로드: https://alfred.stlouisfed.org/help/downloaddata. 공개 거래와 데이터 이용 가능성은 공급자 문서에 근거한 날짜 수준의 가정이며 실제 이전 시스템의 수집 이력으로 보증하지 않는다.
