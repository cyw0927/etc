- 작성: 2026-10-27, **검증 코드 작성·실행 전**에 커밋한다. 이 문서의 커밋 시각이 등록 시점이다.
- 이후 결과를 보고 이 문서의 가설·특징변수·모델 설정·판정 기준을 바꾸지 않는다. 바꿔야 하면 새 버전 문서를 만들고 변경 이유와 그 시점에 이미 본 결과를 적는다.

## 0. 이미 알고 있는 것 (정직한 공개)
- v0.2에서 같은 데이터·같은 워크포워드 구조로 기준모델 2개와 ML 3개(로지스틱·HGB·LightGBM)를 평가했고, **ML이 18개 조합 모두 검증 구간에서 B1(과거 상승비율)보다 Brier가 나빴다**는 집계 결과를 보았다. 최근 2년 홀드아웃(2024-09/10 ~ 2026-09/10)의 집계 결과도 이미 보았다.
- 따라서 이번 홀드아웃은 **완전히 처음 보는 데이터가 아니다.** 아래 가설들은 v0.2 결과가 아니라 기존 문헌의 일반적 주장에서 골랐고, v0.2에서 이 특징 조합들의 성과는 계산해 본 적이 없다. 그래도 진짜 표본 외 증거는 2026-10-27 이후 쌓이는 데이터(전진 검증)뿐이다.
- v0.2에서 본 '과신된 확률' 문제가 보정·축소(아래 A)를 시험하는 동기다.

## 2. 새 후보 모델

### A. 확률 보정·축소 (M1~M3 각각에 적용 → 6개)
각 학습 구간을 시간순으로 나눈다.
- 보정 블록 = 학습 구간 날짜의 **마지막 20%**
- 내부 학습 블록 = 그 이전 표본 중 라벨 종료일이 보정 블록 시작보다 앞선 것(퍼징)
- 기본 모델은 내부 학습 블록에만 적합하고, 보정 블록에서 아래 변환을 추정한 뒤 검증·홀드아웃 예측에 적용한다. 검증·홀드아웃 데이터는 보정에 쓰지 않는다.

| 이름 | 변환 |
|---|---|
| `*_shrink` | 축소: p' = b + λ(p − b). b = 내부 학습 블록의 상승 비율, λ = 보정 블록 Brier를 최소화하는 값(닫힌 해 Σ(y−b)(p−b)/Σ(p−b)²)을 [0, 1]로 자름 |
| `*_platt` | Platt: 보정 블록에서 y ~ logit(p) 로지스틱 회귀(규제 없음에 가깝게 C=1e6) |

### B. 경제 가설 (각각 독립 모델 → 4개)
모든 가설 모델은 같은 형태다: **표준화 + 로지스틱 회귀(C=1.0) + A의 축소(shrink)**. 가설 특징이 결측인 행은 학습에서 빼고, 예측 시 결측이면 학습 구간 상승 비율을 낸다.

| ID | 가설 (문헌 근거) | 특징변수 (예측 시점까지 관측 가능) | 사전 기대 부호 |
|---|---|---|---|
| H1 | **추세 / 시계열 모멘텀**: 지난 1년 오른 자산이 계속 오르는 경향 (Moskowitz·Ooi·Pedersen 2012 등) | `mom_12_1` = 수정종가(t−21)/수정종가(t−252) − 1, `ma_gap_200` = 종가/200봉 평균 − 1 | 둘 다 **+** (모든 자산) |
| H2 | **변동성 레짐**: 최근 변동성이 장기 평균보다 높으면 위험자산의 상승 확률이 낮다 | `vol_20`, `vol_ratio` = vol_20 / vol_252 | 주가지수·BTC에서 **−**. 금·원유·FX는 부호 기대 없음 |
| H3 | **금리 레짐**: 단기금리 상승(긴축)은 주식에, 장기금리 상승은 금에 불리하다 | `us10y_2y`, `us2y_chg60`, `us10y_chg60` (60영업일 변화, %p) | 주가지수: `us2y_chg60` **−**. 금: `us10y_chg60` **−** |
| H4 | **단기 반전**: 직전 1주 하락 후 반등하는 경향 | `ret_5`, `ret_1` | 주가지수 h=5에서 **−** |

`B` 모델과 `A` 모델은 1절의 같은 폴드·같은 홀드아웃으로 평가한다.

## 3. 판정 기준

### 모델 선택 (v0.2와 동일 규칙)
모든 후보(B1, B2, M1~M3, A 6개, B 4개 = 15개) 중 **워크포워드 검증 구간 합산 Brier가 가장 낮은 모델**을 고른다. 홀드아웃은 선택 뒤 한 번만 채점한다.

### 1차 판정: 홀드아웃에서 기준모델보다 나은가
- 각 (후보, 자산, 기간)에 대해 홀드아웃 관측별 Brier 차이 dₜ = Brier(후보)ₜ − Brier(B1)ₜ
- 평균 d의 표준오차는 **Newey–West HAC(Bartlett, 시차 = h)**로 추정. 라벨 기간이 겹쳐 자기상관이 있기 때문이다
- 단측 검정 H₀: E[d] ≥ 0 vs H₁: E[d] < 0 (정규 근사)
- **다중 비교 보정:** B1을 뺀 14개 후보 × 18개 조합 = **252개 검정 전체**에 Benjamini–Hochberg FDR q = 0.10
- **'지지됨'** = (i) BH 보정 후 유의 **그리고** (ii) 검증 구간 합산 Brier도 B1보다 낮음

### 2차 판정 (설명용, 판정을 뒤집지 않음)
- 검증 폴드 중 B1보다 Brier가 낮은 폴드 비율
- 가설 모델(H1~H4): 표준화 계수의 부호가 사전 기대와 일치한 폴드 비율

### 무엇을 실패로 볼 것인가
- '지지됨'이 하나도 없으면 "이번 후보들은 기준모델 대비 개선을 보이지 못함"으로 보고한다
- 지지된 조합이 있어도 위의 홀드아웃 재사용 문제 때문에 **잠정** 결과로 표시하고, 전진 검증 전에는 신뢰도 등급을 '보통' 이상으로 올리지 않는다
- 결과와 상관없이 252개 검정 결과를 모두 산출물(`significance.csv`)과 보고서에 남긴다
