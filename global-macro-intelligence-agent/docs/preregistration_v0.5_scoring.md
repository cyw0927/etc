# v0.5 기준 예측의 최초 만기 채점 사전등록

등록은 구현 및 실제 채점 전에 별도 커밋한다. 기존 예측이나 기존 사전등록은 변경하지 않는다. 이 문서는 예측력 확증이나 신규 후보 비교에 대한 사전등록이 아니다.

대상은 이미 발행된 `pit_baseline_v0.5` 중 SPY, QQQ, GOLD, KOSPI, NIKKEI의 5·20 거래소 봉 예측이다. 발행 장부는 읽기 전용으로 열고, 채점 기록은 별도 `data/operations/issuance/scores.sqlite3`에만 추가한다. 같은 예측의 첫 점수는 수정·삭제하지 않으며 충돌은 차단한다. 과거 예측·점수는 덮어쓰지 않는다.

기준일에서 거래소 실제 정규장 달력으로 h번째 세션이 만기다. 기준일과 만기 사이 예상 세션이 모두 수집 스냅샷에 있어야 한다. 만기 정규장 마감 + 15분 이후 수집이 시작됐고 수집·해시 검사가 완료된 경우에만 점수를 계산한다. 기준 가격은 발행 당시 원본 장부의 가격을 사용하며, 새 스냅샷의 기준일 수정종가가 이를 바꿨으면 가격 비교의 정합성이 불명확하므로 채점을 보류한다. 비유한값·0 이하 가격, 중복 봉, 날짜 변조, 발행이 다음 장 개장 이후, 공급원이나 종목 불일치, 미래 수집시각은 차단한다. 라벨은 `만기가격 > 발행 기준가격`이며 Brier 오차는 `(확률-라벨)^2`다.

점수는 원본 예측키·확률·기준가격, 만기일·가격, 수집 스냅샷 해시, 발행 장부 run ID, 채점 및 수집 시각, 실행 커밋을 남긴다. 다른 입력으로 중복 채점을 시도하면 기존 결과를 유지하고 충돌을 보고한다. 기존 252개 검정·홀드아웃이나 모델 성능 주장을 만들지 않는다. 15분 완충은 Yahoo 측 확정 보장이 아니며, 과거 PIT·배당 수정과 별도의 가격 원천 검증은 여전히 필요하다. 미도래 예측은 대기이며 인위적인 미래 수집자료로 실데이터 채점을 주장하지 않는다.
