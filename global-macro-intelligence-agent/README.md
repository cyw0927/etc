# GMIA — Global Macro Intelligence Agent

> 글로벌 경제·금융·기업 가치평가·국제정세 종합분석 및 시나리오 예측 에이전트  
> 시작: 2026-10-26 · 단계: **v0.1 개념검증(PoC)** · 언어: 한국어

## 프로젝트 한 줄 설명
세계 각국의 경제지표, 주식·코인·금·채권·환율, 기업의 PER·PBR 등 가치평가, 국제정세를 **한데 모아 교차검증하고 시나리오별로 설명**하는 개인용 참고 분석 에이전트다. 자동매매 시스템이 아니다.

## 권장 실행 절차
- **1차 ChatGPT:** 01 마스터 실행 → 실험 001 분석 및 다른 AI용 인계 요약 작성
- **2차 Claude:** 분석 보고서와 02 프롬프트 실행 → 경제적 오류·편향·누락 비판
- **3차 ChatGPT:** 두 결과와 03 프롬프트 실행 → 판정 및 모델 개선
- 다음 실험에서는 Claude가 최초 분석, ChatGPT가 검증하는 방식으로 역할 교대
- 더 공정하게 평가하려면 양쪽 AI를 독립적으로 먼저 실행하고 결과를 서로 공개한 뒤 교차검증한다.

## 핵심 분석 영역
- **거시경제:** 성장·물가·고용·정책금리·국채·재정·무역·환율·유동성
- **금융시장:** 세계 주식 지수·금/은·원유·비트코인·채권·주요 통화
- **기업 평가:** PER·PBR·ROE·ROIC·실적·현금흐름·배당·부채
- **국제정세:** 외신·공식 원자료, 지정학, 제재, 해운, 공급망, 정책
- **예측:** 1주/1개월/3개월, 기본/낙관/비관 시나리오, 반대 조건과 위험
- **검증:** 사실·주장·추론 구분, 시점 엄수, 독립 교차검증, 백테스트 설계

## 중요한 정책
- 지금은 **시뮬레이션 설계 단계**다. 별도 지시 없으면 코딩·실거래·배포 금지.
- 초기 숫자와 사건은 모두 **가상**. 실측 데이터, 검증된 예측 정확도, 실제 백테스트 결과처럼 서술 금지.
- 한국 언론 2차 보도는 국제정세 기본 수집원에서 제외하고, 다양한 외신과 1차 자료로 교차검증한다. 한국의 공식 경제통계는 사용 가능.
- 긍정/부정/모호함은 **기사 논조가 아니라 국가·산업·자산에 미치는 영향별**로 판정.
- 근거 없이 정밀한 확률이나 수익률을 만들어내지 않는다. 확률은 실제 검증·보정 이전에는 설명용.
- 뉴스 반복 인용을 독립적인 다중 검증으로 취급하지 않는다.
- GitHub 저장소가 **공개(public)** 상태이므로 API 키, .env, 개인자료, 유료 기사 전문 등을 커밋하지 않는다.
